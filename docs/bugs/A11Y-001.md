# A11Y-001: Admin "Create product" wizard is mounted twice and hidden from assistive technology

| Field        | Value                                                                                                 |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| Severity     | **Major** — screen-reader and voice-control users cannot create products at all                       |
| Priority     | **Medium**                                                                                            |
| Component    | Medusa Admin dashboard 2.22.2, route `/app/products/create`                                           |
| WCAG 2.1     | 4.1.2 Name, Role, Value (A); 1.3.1 Info and Relationships (A)                                         |
| Environment  | Chromium 156, admin served by the backend in production mode; see [findings](../findings.md#findings) |
| Related code | `src/pages/admin.ts` › `AdminProductCreatePage` (workaround)                                          |

## Steps to reproduce

1. Sign in to the admin, open **Products → Create** (or go to `/app/products/create` directly).
2. In DevTools run:
   `[...document.querySelectorAll('[role=dialog]')].map(d => d.getAttribute('aria-hidden'))`

## Expected

One dialog, not hidden: `[null]`. Form fields reachable by role and label (e.g. textbox "Title").

## Actual

- Two dialogs with identical forms are in the DOM, both visible on screen (stacked).
- Each carries `aria-hidden="true"` — each copy hides the other (the modal library hides everything
  outside the active dialog, and there are two "active" dialogs).
- Result: the accessibility tree contains **no** form controls. In Playwright,
  `getByRole('button', { name: 'Continue' })` finds 0 elements while the button is visible.
- The text inputs also have no accessible names (labels are not linked to inputs).

By contrast, **Promotions → Create** mounts a single dialog and is fully accessible by role.

## Evidence

Output of the inspection script used while writing the page object:

```
dialogs 2 aria-modal 0
continue buttons: [{ hiddenBy: 'radix-:r29:', inDialog: true, dataState: 'open' },
                   { hiddenBy: 'radix-:r2f:', inDialog: true, dataState: 'open' }]
via list page: forms 2, buttons named "Continue": 0
```

## Impact

Product creation is impossible with assistive technology; the duplicate mount also doubles the work
done on open (two form instances).
